The background system I would use

Do not choose only one. The website should move between these background types so each section has a clear role.

Base website background

Sky atmosphere base. Light gradient, no heavy dark blue, very low texture.

Functional sections

White with blue corners for search, forms, services details, visa flow, and dashboards.

Signature sections

3D services and map route texture for services, Smart Trip Planner, and hero moments.
